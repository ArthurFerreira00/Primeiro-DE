# 🍳 O Livro de Receitas da Turma

Bem-vindo(a) ao nosso projeto colaborativo! O objetivo desta atividade é praticar o fluxo de **Pull Request (PR)** sem usar nenhuma linha de comando. Vamos construir juntos um livro digital usando apenas o navegador!

---

## 🛠️ Como Participar (Passo a Passo pelo Navegador)

Siga os passos abaixo diretamente aqui no site do GitHub para enviar a sua receita.

### Passo 1: Entre na pasta de receitas
1. Olhe para a lista de arquivos acima e clique na pasta chamada **`receitas`**.

### Passo 2: Crie o seu arquivo
1. No canto superior direito da lista de arquivos, clique no botão **"Add file"** e depois em **"Create new file"**.
2. No campo onde diz `Name your file...`, digite o nome da sua receita com a extensão `.md` no final. 
   * *Exemplo:* `brigadeiro.md` (use letras minúsculas e troque espaços por traços).

### Passo 3: Escreva a sua receita
1. No campo de texto grande abaixo, copie, cole e preencha o modelo abaixo com os seus dados:

```markdown
# 🍫 Nome da Receita (Ex: Brigadeiro)
**Enviado por:** Seu Nome

### 🛒 Ingredientes
- 1 lata de leite condensado
- 1 colher de sopa de manteiga
- 3 colheres de sopa de chocolate em pó

### 🥣 Modo de Preparo
1. Misture todos os ingredientes em uma panela.
2. Cozinhe em fogo baixo, mexendo sempre, até desgrudar do fundo.
3. Deixe esfriar e faça as bolinhas.
```

### Passo 4: Salvar a receita (Commit) e Criar a Branch
1. No canto superior direito, clique no botão verde **"Commit changes..."**.
2. Uma janelinha vai abrir. Preencha assim:
   * No primeiro campo (Commit message), escreva: `Adiciona receita de [Nome do Prato]`.
   * **Importante:** Abaixo, selecione a opção **"Create a new branch for this commit and start a pull request"** (Criar uma nova branch para este commit e iniciar um pull request).
   * O GitHub vai sugerir um nome de branch automaticamente (ex: `seu-usuario-patch-1`). Você pode deixar como está.
3. Clique no botão verde **"Propose changes"** ou **"Create branch"**.

---

## 🚀 Finalizando o Pull Request (PR)

1. Após o passo anterior, o GitHub vai te redirecionar para uma tela chamada **"Open a pull request"**.
2. No campo de texto, você pode deixar um recado para o professor (ex: *"Professor, mudei a receita para incluir o doce que comentei!"*).
3. Clique no botão verde **"Create pull request"**.
4. Pronto! Sua receita foi enviada e está aguardando a aprovação do professor para entrar no livro oficial!
